# PHP Hello World with Docker

A simple PHP "Hello World" application running in Docker.

## Project Structure

```text
nama-project/
├── docker-compose.yml
└── src/
    └── index.php
```

## How to Run

1. Open your terminal in the project directory.
2. Start the container:
   ```bash
   docker compose up -d
   ```
To stop and remove the running container, run:
```bash
docker compose down
```
